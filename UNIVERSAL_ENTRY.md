# Общая ссылка участника

Постоянный адрес рабочей игры: `https://culture-quest-z.onrender.com/student.html`.

В этом исправлении ссылка не содержит временного допуска. Обычный участник регистрируется по имени, пока преподаватель открыл вход. Закрытие входа или окончание его срока блокирует новую регистрацию. Следующее открытие или продление снова разрешает вход по тому же адресу. Старые ссылки с `#join=…` тоже продолжают работать, пока вход открыт: их токен больше не является условием регистрации.

Это публичный вход **обычных игроков**, а не код «Универсал» или доступ администратора. Проверки пароля преподавателя, серверных административных ключей, ролей, согласия, устройства, вместимости и ограничений частоты сохранены. Браузерное имя и параметры ссылки не повышают права.

Пульт преподавателя копирует постоянный адрес даже при закрытом входе. Кнопка «Продлить вход» сохраняет этот адрес. Временные токены остаются в совместимом ответе серверного API для старых клиентов, но не нужны новым участникам.

Ветка: `fix/universal-student-entry`. Обновляются только серверная проверка регистрации, тексты/ссылка пульта и соответствующая проверка безопасности. Google-вход, лобби, банк вопросов и сохранённые матчи этим исправлением не меняются. Миграция базы не требуется.

Проверка: `node --test tests/security-hardening.test.js` — десять локальных сценариев, включая прямой вход без приглашения, старую ссылку после продления, блокировку закрытой регистрации и отсутствие административных прав у вошедшего игрока. Рабочие участники для теста не создаются.
