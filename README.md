# Мәдениеттану 3D · Универсальная платформа

Раздельные интерфейсы участника (`student.html`, `student.js`) и преподавателя (`teacher.html`, `teacher.js`), авторитетный Node.js + Socket.io, PostgreSQL или локальное атомарное файловое сохранение. Three.js и библиотеки обработки PDF/DOCX раздаются этим же сервером. GitHub Pages недостаточно: приложению нужен работающий сервер.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run setup
npm start
```

Открыть `http://localhost:3000/student.html` и отдельно `http://localhost:3000/teacher.html`. Локальные `.env` и `data/` не публикуются в Git. Тесты: `npm test`.

На Render используется один Web Service: build `npm ci --omit=dev`, start `npm start`, branch `main`. Сервер слушает `0.0.0.0` и порт `PORT`. Настройки Environment:

- `TEACHER_PASSWORD`: пароль преподавателя длиной 8–256 символов.
- `SESSION_SECRET`: случайный секрет минимум 32 символа.
- `DATABASE_URL`: внутренний адрес существующего PostgreSQL в том же регионе Render.
- `CREATOR_ERNUR_CODE`, `CREATOR_ADILET_CODE`: два разных непубличных персональных кода длиной 26–128 символов без пробелов. После первого входа замените известные коды случайными через «Приглашения и защита входа». В базе сохраняется хеш замены; старое значение Environment перестаёт давать доступ. Не публикуйте коды в исходниках.

История игры и чатов сохраняется в PostgreSQL автоматически; дополнительный сервис не нужен. `/health` сообщает `storage`, `chatStorage` и готовность персонального входа. Для Web Service можно выбрать Health Check Path `/health`. При подключении репозитория через публичный Git URL обновление запускается Manual Deploy → Deploy latest commit. При подключённом GitHub-провайдере учитывайте настройку автоматической публикации и не запускайте второй deploy поверх уже начавшегося.

## Форматы пары

В панели преподавателя формат и рейтинг находятся под списком участников в общей прокрутке и изначально свёрнуты. Переключение разрешено в лобби. После завершённого вопроса нажмите «Вернуться в лобби»; состав и баллы сохраняются. Во время активного вопроса переключение заблокировано.

**Аймақтық одақ:** начальные команды сохраняются, преподаватель задаёт 1–50 команд и 1–50 мест в каждой. При расширении сначала добавляются остальные области и города республиканского значения, затем городские команды внутри областей; например, Жаңаөзен в Маңғыстау. Студент сначала выбирает область, затем её команду или город. Дополнительный город можно создать вручную. Одновременный вход ограничен 500 участниками; это защитная граница, не обещание нагрузки бесплатного тарифа. Верный ответ даёт +25 культурного ресурса и +5% экономики; при экономике ниже 30% восстановление +15%. Ошибка снижает экономику на 20%, минимум 15%. Ресурс ограничен 1000.

Новый командный выбор сначала появляется в виде предложения. Сокомандники видят имя и вариант и могут подтвердить его; автор может подтвердить или отменить. Без дополнительного действия выбор принимается через семь игровых секунд. Пауза останавливает этот отсчёт. После подтверждения голос учитывается в большинстве. До завершения таймера принятый выбор можно заменить новым предложением. Ручная отправка фиксирует текущий ответ команды; по таймеру учитывается большинство принятых голосов. Если подтверждения ещё нет, такой выбор не участвует в подсчёте. Это особенно важно в последние семь секунд: используйте явное подтверждение.

Альтернативное правило «Лидер»: лидер выбирает вариант, остальные голосуют «согласен / не согласен». После согласия строгого большинства лидер вручную отправляет ответ. Смена варианта или состава сбрасывает это голосование. Сервер не отправляет такой ответ за лидера по таймеру. По умолчанию лидер — первый обычный участник; преподаватель назначает другого в карточке игрока.

Обмен ресурсами включается отдельно. Между вопросами лидеры предлагают культурные очки в обмен на экономику; принимающая команда подтверждает сделку. Проверки баланса и пределов выполняются заново при принятии. Войны не реализованы и не включаются.

**Жеке сайыс:** вход только по имени, без выбора области и командного лимита. У каждого отдельные ответы, капитал, серия и место. База за правильный ответ — 25, умноженные на коэффициент серии до этого ответа: `1 + min(серия, 8) × 0.25`, максимум ×3. Результат округляется; первый верный ответ даёт 25, второй подряд — 31. Ошибка сбрасывает серию, не списывает капитал и не меняет экономику областей. Капитал ограничен 1000. На проекторе показываются десять лидеров, полная ведомость доступна в CSV. Проверены 150 независимых участников локально; это проверка протокола, а не гарантия нагрузки бесплатного тарифа Render.

## Персональная диагностика

Введите персональный код в поле имени и выберите область/команду; в Solo нажмите «Присоединиться». После кода можно дописать имя через пробел. Без имени используются «Ернур» и «Адлет». Персональные сессии играют вместе с командой и могут войти сверх её лимита. Каждый из двух доступов занимает одну сохранённую сессию: повторный ввод занятого кода отклоняется. Закрытие браузера не освобождает доступ сразу: после 30 минут без действий сервер завершает сессию и освобождает место. Восстановление до истечения этого срока использует защищённую cookie; добровольный выход или принятый владельцем запрос преподавателя также освобождает доступ.

Служебная шторка создаётся в DOM только для авторизованной сессии. Открытие: удерживать заголовок «Мәдениеттану» две секунды, нажать угловую зону 20×20 px либо F9/`~` на компьютере. Виброотклик используется только если браузер поддерживает его. Шторка занимает 69–70% высоты. Тап по затемнению, свайп вниз с верхней ручки, крестик или Escape закрывают её сразу.

- **God Eye:** текущий правильный ответ, рейтинг всех участников или команд и банк будущих вопросов. Делегаты без разрешения «Вопросы» правильные ответы не получают.
- **Live Control & Identity:** смена собственного отображаемого имени, ресурсы/капитал, +20% экономики, восстановление экономики до 100%, вопросы, таймер и освобождение слота.
- **Hotfix JSON:** команды, личный рейтинг и банк вопросов. Применение проверяет ревизию, диапазоны, участников и географию. Формат переключается отдельной командой. Добавить роль, секрет, нового участника или выполнить JavaScript через JSON нельзя. Перед применением сохраняется копия.

Сессии браузера сохраняются в HttpOnly/SameSite cookie, на Render дополнительно Secure. Старый токен однократно переносится из localStorage с заменой; прежние локальные ключи удаляются. Подмена имени, URL, DOM или флага роли не даёт прав: сервер проверяет каждую команду. Адилет выдаёт одноразовые приглашения с отдельными разрешениями и сроком, может отозвать доступ. Каждый код активируется один раз; отдельного лимита в две делегированные сессии нет. Оба владельца могут открыть полный teacher.html из своей панели с сохранением персональных полномочий. Скрытый жест не является защитой.

Через 30 минут без действий выходят все: студенты, делегаты, оба персональных владельца и преподаватель. Реальные нажатия, ввод и прокрутка продлевают активную сессию; автоматические обновления, переподключение и фоновая подписка чата — нет. Срок хранится на сервере и переживает перезапуск. Истечение срока освобождает место без подтверждения владельца и не сбрасывает очки команды или вопросы. При первом внедрении существующие сессии получают 30 минут на возобновление активности. Время активности не входит в публичное состояние или JSON-редактор.

## Сохранение и миграция

Игра хранится в `culture_quest_state`, чат — отдельно в `culture_quest_chat`. Без PostgreSQL используются `STATE_FILE` (по умолчанию `data/game-state.json`) и соседний файл `.chat.json`. Запись атомарна; при ошибке действие не публикуется. Повреждённое сохранение не заменяется новой игрой.

Обновление переносит предыдущие команды в десять областей, сохраняет идентификаторы участников, токены, вопросы и принятые голоса. Исходный снимок сохраняется в приватном `migrationBackup`. Старые региональные ресурсы сохраняются для соответствующих областей; прежняя экономика ниже 15% повышается до порога. Если обычных участников больше 40, выбирается Solo, чтобы не удалять людей. Возврат в командный формат блокируется до освобождения лишних мест. Совместимость старого движка сохраняется для миграционных регрессионных тестов; рабочий сервер всегда включает универсальные правила.

Расширенная персональная панель открывается прежним жестом (удержание заголовка 2 секунды), через угловую микро-зону или F9. В Live Control & Identity доступны перенос себя в любую область, перенос и переименование игроков, массовое исключение обычных участников, изменение рейтинга и экономики, редактирование/добавление/удаление вопросов, импорт силлабуса, запуск выбранного вопроса, управление лобби, экспорт CSV и сброс матча. Персональный администратор может сменить формат во время раунда: итоги подводятся и открывается лобби одной серверной операцией. Ограничения вместимости, экономики и ресурса проверяются сервером.

Два персональных администратора не могут исключать друг друга. Преподаватель нажимает «Запросить выход» в карточке участника; адресат получает окно «Остаться / Подтвердить выход», даже когда панель закрыта. Запрос хранится в БД и возвращается после F5 или перезапуска сервера. При отказе вход и полномочия сохраняются; повторный запрос возможен через 30 секунд. Ответить за другого администратора нельзя. Обычный выход из собственной сессии остаётся доступен. Массовая очистка и сброс игры сохраняют две персональные сессии; JSON-патч, удаляющий любую из них, отклоняется целиком. Сброс обнуляет их игровой рейтинг, сохраняя право доступа.

«Перезагрузить интерфейсы» обновляет подключённые страницы преподавателя, участников или все авторизованные экраны (один вызов в минуту). Серверный процесс, БД и принятые ответы не сбрасываются. «Сигнал / помеха» — временная визуальная симуляция без записи экрана, звука и тяжёлого canvas-шума. Адилет задаёт длительность 100–60000 мс без cooldown; делегаты — только при явно выданном разрешении, со своей длительностью и индивидуальным cooldown. Можно выбрать проектор либо одного подключённого обычного игрока. Персональные и делегированные администраторы защищены от адресной помехи. Эффект завершится по таймеру; reduced-motion отключает анимации.

Непрозрачный токен и метаданные `playerId`, `teamId`, режим и имя сохраняются в `localStorage`. После F5 сервер восстанавливает того же участника, не занимая второе место. Если браузер очищает локальные данные или включён приватный режим, восстановление после закрытия не гарантируется. После исключения старый токен больше не предоставляет доступ.

## Вопросы и документы

Преподаватель создаёт, ищет, редактирует и удаляет вопросы, видит правильные и предварительные ответы команд/участников до итогов. Активный раунд использует свой снимок: правки банка действуют со следующего запуска. Версии защищают от перезаписи чужих изменений. В универсальных форматах база начисления фиксирована на 25 независимо от исторического поля баллов в банке.

Импорт силлабуса принимает PDF, DOCX, TXT до 10 МБ. Бесплатный подбор использует определения из текста и учебный банк; внешнего ИИ/API нет. Темы, вопросы, правильные ответы и источники сначала показываются преподавателю как черновики. Скан без текстового слоя требует предварительного OCR. Перед добавлением нужно проверить соответствие вашей программе.

«Скрыть ответы для проектора» скрывает закрытые ответы, редакторы, служебные формы, чаты и карточку авторов. Лидерборд Solo остаётся видимым. Это отображение в авторизованной панели преподавателя, а не публичная ссылка на админку.

## Чаты

Общий чат доступен всем вошедшим участникам и преподавателю. В командном канале общаются сокомандники; преподаватель и персональная диагностика могут помогать и модерировать обычные команды. Личное обращение Ернуру и Адлету читают только его автор и обе персональные сессии; другие студенты и преподаватель его не получают. Обращение исключённого участника доступно в архиве без новых отправок. Карточка «Сделано Адлетом и Ернуром» закрывается крестиком и возвращается через «Авторы проекта» в чате.

Только текст: до 600 символов, 8 строк, 8 новых сообщений за 10 секунд на игрока. Последние 80 сообщений каждого канала, до 500 суммарно. Свои сообщения можно удалить; модерация доступна только для разрешённых каналов. При удалении текст стирается из сохранённой истории. Повтор с тем же ID не дублирует сообщение, пока оно хранится. История не попадает в JSON игры и сохраняется независимо от игрового сброса.

## Мобильная карта и соединение

Карта подгружается отдельно после входа, не блокируя форму и вопросы. На экране до 600 px её высота ограничена 230 px; она сворачивается отдельной кнопкой. На телефонах по умолчанию pixel ratio не выше 1 и выключены тени; кнопка «Экономно / Детально» сохраняет выбор в браузере, общий предел — 1.5. На мобильном рельеф менее плотный. Кадры запрашиваются при движении камеры, изменении карты и завершении анимаций; неподвижная, свёрнутая, невидимая карта и фоновая вкладка не держат постоянный цикл. Новые голоса без изменений географии не перерисовывают карту.

Подпись закреплена над центром города. Её размер считается по глубине камеры и высоте холста; при приближении текст плавно увеличивается от 112 до 200 экранных пикселей. Проверка пересечений использует фактический размер подписи. Все 17 областей и три города остаются полноценными географическими объектами атласа; десять из них используются как игровые области.

Клиент восстанавливает соединение с фиксированной задержкой две секунды и показывает статус пробуждения Render. Указанные 30 секунд в подсказке — ориентир, не гарантия времени холодного запуска. Действия подтверждаются сервером; не сохранённое изменение не считается выполненным.

## Версия стабилизации и подготовки к передаче

- При новом входе сервер проверяет согласие версии `2026-10-23`, сохраняет время и версию. Существующие сессии продолжают работу без фиктивного согласия задним числом. Гость видит свободные места, но не имена и не ответы.
- Название организации, логотип, цвета, оператор данных и предметы настраиваются ниже основных панелей. Логотип хранится у сервера, не пересылается целиком при каждом голосе; разрешены PNG/JPEG/WebP до 150 КБ. Внешние шрифты не загружаются.
- Банк вопросов разделён полем `subject`. Вопросы без поля относятся к «Мәдениеттану»; импорт и новые вопросы получают текущий предмет. Рейтинг не обнуляется автоматически при смене предмета.
- Три последние серверные точки восстановления и скачиваемый архив игры AES-256-GCM. Автокопия перед JSON-патчем, сбросом и массовой очисткой; восстановление ставит текущий вопрос на паузу, сохраняет действующие персональные сессии и отзывает делегированные доступы. Архив не включает чат и не заменяет резервирование всей БД. Для переноса архива нужен прежний SESSION_SECRET.
- CSV и командный рейтинг используют общую формулу `ресурс + экономика × 5`. Старые скрытые права не переносятся из архива. Ограниченные администраторы не получают правильные ответы без разрешения на вопросы.
- Правильный пароль не блокируется из-за предыдущих ошибок на общем IP; 15-минутной блокировки нет. Защита от частых некорректных действий сохранена.
- `npm test`: десять быстрых проверок; `npm run test:full`: весь регрессионный набор. Количество учебных вопросов по умолчанию — десять, независимо от числа автоматических тестов.

Перед реальной обработкой имён в Казахстане отдельно проверьте требования к локализации баз и трансграничной передаче. Зарубежное размещение и галочка согласия не являются доказательством соответствия. Необходимо заполнить оператора и контакт, определить сроки удаления и подтвердить права на логотип/учебные материалы.
