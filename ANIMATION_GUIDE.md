# Подключение готовых анимаций

Общий проигрыватель: `achievement-player.js`. Подключены `award-zero-card.js` (8,2 секунды), `award-scenario-reader.js`, `award-neon-summit.js`, `award-determination.js` и `award-daily-training.js` (по 8 секунд). Сцены адаптированы из присланных файлов. Не переписывать проигрыватель для каждой следующей анимации.

1. Перенести рисование из HTML в `award-<имя>.js`. Убрать собственную загрузку Three.js, кнопки, RAF и обработчики окна.
2. Экспортировать `durationMs`, `captionAtMs` и `createAnimation({THREE,reducedMotion,lowPower})`. Фабрика создаёт сцену один раз и возвращает `scene`, `camera`, `update(seconds,deltaSeconds)`, при необходимости `resize(width,height)`, `setPointer(x,y)`. Геометрию, материалы и текстуры освобождает общий проигрыватель.
3. В `achievement-animations.js` добавить ID достижения, относительный путь к модулю и продолжительность в `ANIMATION_DURATIONS`. Сервер разрешает этот файл автоматически; изменения серверных обработчиков или условий выдачи не нужны.
4. Открыть штатный административный предпросмотр. Проверить запуск, закрытие и повтор; для нового визуального эффекта не повторять проверки экономики и выдачи наград.

Проигрыватель загружает Three.js проекта только при запуске, ограничивает отрисовку 30 кадрами/с и pixel ratio, показывает статичный финал при reduced-motion. Закрытие, Escape, скрытие страницы и уничтожение плеера останавливают кадры, таймеры и обработчики и освобождают геометрию, материалы, текстуры и WebGL-контекст. Повторное открытие создаёт отдельный экземпляр. Незавершённая загрузка не создаёт сцену после закрытия.

Фон 3D-сцены должен оставаться прозрачным (`scene.background = null`): общий проигрыватель создаёт WebGL-контекст с `alpha: true` и рисует только полупрозрачную подложку, через которую виден интерфейс игры. Не добавлять полноэкранную непрозрачную плоскость. При ручном вручении награды активный таймер вопроса автоматически приостанавливается на сервере на продолжительность анимации с запасом 1,5 секунды и затем продолжается; административный предпросмотр время не меняет. Нажатие преподавателем «Пауза/Продолжить» во время показа отменяет автоматическое продолжение. Обычные 2D-сцены можно подключать отдельным адаптером к этому же интерфейсу; не создавать под каждую новый UI и новую схему запуска. Исходные HTML пользователя не изменять.

Каждое из шести легендарных достижений и итоговый перк помечены `world:true`. Сервер передаёт всем авторизованным участникам и преподавателю короткое событие с ID команды, названием и временем; чужие личные награды и ID получателя не раскрываются. `scene3d.js` создаёт и затем освобождает лёгкую 3D-версию символа над областью награждённого. Личная кинематографическая сцена доступна владельцу; остальные видят общую карту и небольшое уведомление, не перекрывающее её. Новые мировые награды должны получать как собственную сцену, так и лёгкий символ на карте.
